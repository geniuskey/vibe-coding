# LLM에게 우리의 지식을 가르치는 법

LLM 시대의 지식 정리 세미나 슬라이드 (reveal.js, 단일 `index.html`).
**LLM 위키 · RAG · 지식 그래프 · 온톨로지** — 네 개념을 이론으로 소개하고,
후반부는 Claude Code 같은 에이전트에게 **프롬프트로 시키는 실습**으로 전부 직접 만들어 봅니다.

## 무엇을 다루나

| 챕터 | 내용 | 형식 |
| --- | --- | --- |
| CH 1 · LLM과 지식 | 파라미터 지식 vs 컨텍스트 지식, 환각의 정체와 처방, 지식 주입 3가지 방법(붙여넣기·RAG·파인튜닝), 좋은 "먹이"의 4조건 | 이론 |
| CH 2 · LLM 위키 | 흩어진 팀 지식의 문제, 사람의 위키 vs LLM의 위키, Markdown이 공용어인 이유, 작성 4원칙, 진입점(CLAUDE.md·llms.txt·INDEX.md), 위키의 한계 | 이론 |
| CH 3 · RAG | 검색 증강 생성 3단계, 임베딩(의미를 좌표로), 벡터 DB, 청킹, 키워드 vs 벡터 vs 하이브리드, 실패 모드 4가지, Agentic RAG | 이론 |
| CH 4 · 지식 그래프 | 트리플(주어·관계·목적어), multi-hop 질문, GraphRAG, "전부 그래프화하지 마라" 현실 조언 | 이론 |
| CH 5 · 온톨로지 | 용어 불일치 문제, 구조화의 사다리(폴더→태그→택소노미→온톨로지), 구성요소 5가지, RDF/OWL/SPARQL/schema.org 이름 소개, 용어사전+스키마로 시작하기 | 이론 |
| CH 6 · 큰 그림 | 4가지 도구 비교표, 팀 지식봇 조합 아키텍처 | 이론 |
| 실습 0~6 | 샘플 문서 생성 → 위키화 → CLAUDE.md → 미니 RAG(청킹·검색 비교·인용 답변) → 그래프 추출·시각화 → 미니 온톨로지(용어사전+스키마+제약 검사) → 종합 설계서 | 실습 |
| 부록 | 프롬프트 치트시트 | — |

총 42장, 약 90분 (이론 ~50분 + 실습 ~40분) 구성입니다.
실습 준비물은 **에이전트 도구(Claude Code 등) + 빈 폴더**가 전부입니다 — 임베딩 API나 벡터 DB 설치 없이
개념을 체험하도록 설계되어 있습니다.

## 실행

- **정적 열람**: `index.html`을 브라우저로 열거나 정적 호스팅(GitHub Pages 등)하면 슬라이드만 동작합니다.
- **실제 발표 (실시간 Q&A 포함)**: 저장소 루트에서

  ```bash
  npm run dev
  # 발표자: http://localhost:8080/knowledge/?present
  # 청중:   http://localhost:8080/knowledge/
  ```

  이 덱은 `knowledge` 방(room)을 사용하므로 다른 덱(메인·워크숍·컨텍스트·깃허브)과 질문이 섞이지 않습니다.
