# 바이브 코딩 실습 워크숍 — 강사용 런북

`workshop/index.html`(8시간 핸즈온)을 **진행하는 사람**을 위한 운영 가이드다.
슬라이드에는 참가자용 정보가, 이 문서에는 강사·조교용 정보가 들어 있다.
(각 슬라이드의 발표자 노트(`S` 키)에도 슬라이드별 진행 멘트가 있다 — 이 문서는 그 위에 얹는 운영 계획이다.)

### 시간이 밀렸을 때 — 스킵 우선순위

밀린 만큼 아래 순서대로 자른다 (위가 먼저):

1. **보너스·🚀 더 해보기 전부** — 원래 밸브다. 아깝다고 붙잡지 말 것
2. **★ 심화 트랙** — 전체 진행에서는 원래 건너뛰는 파트 (빠른 그룹용)
3. Part 2에서 실습 2개 축소 — 영문 메일·표 정리는 "프롬프트만 보여주고 각자 나중에" 처리 가능
4. Part 4의 공정 계산기 — SPC·대시보드가 학습 목표를 이미 커버한다
5. Part 5에서 요약 메일·엑셀 자동화 축소 — "나만의 스킬"은 자르지 말 것 (다음 세미나로 이어지는 고리)

**절대 자르지 않는 것**: 워밍업, 고장난 앱 고치기(복구 경험), 오후의 검증 습관, 미니 프로젝트와 공유.
이 네 개가 "자신감"이라는 오늘의 진짜 목표를 만든다.

### 반대로 시간이 남으면

- 각 실습의 🚀 더 해보기로 심화
- ★ 심화 트랙을 강사 라이브 데모로 (특히 GitHub Pages 배포 — 반응이 가장 좋다)
- 미니 프로젝트 공유를 3분 → 5분으로 늘리고 질문을 받는다

## 실습 판정 기준 (강사용)

슬라이드마다 "여기서 볼 것"이 있지만, 진행 판단용 공통 기준은 다음과 같다.

| 파트 | 이 정도면 통과 (다음으로 넘어가도 됨) | 흔한 실패 → 처방 |
| --- | --- | --- |
| 1 첫 결과물 | 브라우저에 뭐라도 뜬다 + 수정 요청 1회 성공 | 파일이 어디 생겼는지 모름 → "방금 만든 파일 경로 알려줘" 프롬프트 |
| 2 비개발 업무 | 결과물을 실제 업무 문서에 붙여넣을 수 있는 수준 | 샘플 텍스트를 안 만들고 실데이터를 꺼내려 함 → 보안 약속 리마인드 |
| 3 데이터 | 숫자 하나를 원본과 대조해 봤다 (검증 경험) | 차트가 그럴싸해서 그냥 믿음 → "정답 심기"를 강제 과제로 |
| 4 도메인 도구 | 쪼개서 시키는 흐름(뼈대→데이터→차트)을 한 번 밟았다 | 한 방 프롬프트로 전부 시키고 실패 → 쪼개기 패턴 슬라이드로 복귀 |
| 5 자동화 | "내 업무 중 자동화할 것"을 하나 말할 수 있다 | 파일 일괄 처리를 실폴더에 하려 함 → 반드시 연습 폴더 사본으로 |
| 6 미니 프로젝트 | 완성도 무관 — 시연 + "다음에 뭘 더 할지" 한 마디 | 주제를 못 정하고 15분 소모 → 아이디어 카드 슬라이드에서 강제 선택 |

## 공통 트러블슈팅 대본

현장에서 반복되는 상황과 1차 대응. 설치 자체의 문제는 [0교시 트러블슈팅 TOP 5](../setup/)를 그대로 쓴다.

| 상황 | 대응 |
| --- | --- |
| 도구가 응답 없음/한도 초과 | 사용량 한도일 가능성 — 잠시 쉬거나 짝의 노트북으로. 고장이 아니라고 안심시키기 |
| 에러가 났는데 굳어 있음 | "에러는 복붙" 규칙 리마인드 — 첫 복붙 성공자를 공개 칭찬하면 이후 질문이 확 준다 |
| 결과가 산으로 감 | 복구 문장 사전 슬라이드로 — "아까 잘 되던 버전으로 되돌려줘" |
| 진도 격차가 벌어짐 | 빠른 사람에게 🚀 더 해보기 + 조교 역할 부여. 느린 사람은 완성보다 "루프 경험"에 집중시키기 |
| 실데이터를 쓰고 싶어 함 | 오늘은 금지(보안 약속). "실데이터로 넘어가기 전 체크리스트" 슬라이드를 가리키기 |
| 한글 깨짐(CSV/엑셀) | "인코딩 문제인 것 같아, UTF-8로 다시 저장해서 읽어줘" 프롬프트 |

## 진행 팁

- **속도의 기준은 중앙값**: 최속·최지연 참가자가 아니라 방의 중간에 맞춘다. 양끝은 밸브(보너스/조교)로 흡수.
- **화면 공유보다 URL**: 발표 모드(`?present`)로 진행하면 청중 화면이 자동 동기화된다. 뒤처진 사람은 "발표자 따라가기"를 끄고 자기 속도로 볼 수 있다.
- **질문은 Q&A 위젯으로**: 손들기보다 심리 장벽이 낮다. 쉬는 시간마다 질문 기록을 훑고 공통 질문만 전체 공유.
- **점심 룰렛**: 오전 결과물(룰렛)로 점심 메뉴를 정하는 것을 잊지 말 것 — "내가 만든 게 실제로 쓰인다"는 첫 경험이다.
- **마무리 15분**: 공유 시간은 절대 희생하지 않는다. 남에게 보여주는 순간이 자신감의 완성이다.

- 실습을 추가/삭제하면 스킵 우선순위 목록도 재검토할 것
