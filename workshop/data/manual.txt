XV-700 진공 이송 모듈 유지보수 매뉴얼 (가상 실습용 문서)
================================================================
본 문서는 워크숍 실습용으로 작성된 가상의 매뉴얼입니다.

1장. 개요
XV-700은 로드락과 공정 챔버 간 웨이퍼 이송을 담당하는 진공 로봇 모듈이다.
구성: 로봇 암(RA-2), 슬롯 밸브 4식, 진공 게이지 PG-1/PG-2, 정렬기(AL-9).

2장. 일상 점검 (매일)
- 로봇 암 티칭 좌표 드리프트 확인 (±0.15 mm 이내)
- PG-1/PG-2 지시값 비교: 편차 5% 초과 시 게이지 교정 의뢰
- [경고] 체임버가 대기압임을 확인하기 전에는 절대 뷰포트를 개방하지 말 것

3장. 주간 점검 (매주 월요일)
- 슬롯 밸브 O-링 육안 점검, 파티클 부착 시 IPA 와이핑
- 로봇 암 벨트 장력 점검 (처짐 3 mm 이내)
- 정렬기 센서 캘리브레이션 (표준 웨이퍼 사용)

4장. 월간 점검
| 항목 | 주기 | 기준 |
|---|---|---|
| 로봇 암 그리스 도포 | 매월 | 지정 그리스 G-77만 사용 |
| 슬롯 밸브 개폐 수명 카운터 | 매월 | 80만 회 초과 시 교체 계획 수립 |
| 진공 리크 체크 | 매월 | 5×10^-9 Torr·L/s 이하 |
| 케이블 캐리어 마모 | 매월 | 균열 발견 시 즉시 교체 |

[경고] 그리스 도포 작업은 반드시 로봇 전원 차단(LOTO) 후 수행할 것.
[경고] G-77 이외의 그리스 사용 시 아웃개싱으로 진공도가 저하될 수 있음.

5장. 고장 대응
- PG-2 무응답: 케이블 커넥터 재체결 → 재발 시 게이지 교체 (부품번호 PG2-K402)
- 웨이퍼 핸드오프 실패: 티칭 좌표 재확인 → 정렬기 센서 오염 점검
- 슬롯 밸브 응답 지연: 에어 공급압 확인 (0.5 MPa) → 솔레노이드 밸브 점검
[경고] 진공 중 로봇 암 수동 조작(조그)은 웨이퍼 파손과 암 충돌을 유발할 수 있으므로
      반드시 시뮬레이션 모드에서 경로를 확인한 후 수행할 것.
