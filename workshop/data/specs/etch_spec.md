# ES-2041 식각 공정 스펙 (가상 실습용)

> 본 문서는 워크숍 실습을 위한 **가상** 문서입니다. 실제 공정과 무관합니다.

## 1. 적용 범위
본 스펙은 ETCH-01/02 장비의 산화막 식각 공정 P-OX-ETCH 계열 레시피에 적용한다.

## 2. 공정 조건
| 항목 | 규격 | 비고 |
|---|---|---|
| 공정 압력 | 55 ± 5 mTorr | 안정화 30 s 후 판정 |
| RF 소스 파워 | 800 ± 20 W | |
| RF 바이어스 파워 | 120 ± 10 W | |
| 척 온도 | 40 ± 2 °C | |
| C4F8 유량 | 45 ± 2 sccm | MFC-1 |
| O2 유량 | 8 ± 1 sccm | MFC-3 |

## 3. 공정 중단 기준
- 공정 압력이 **120 mTorr를 초과하면 공정을 중단**하고 설비팀에 통보한다.
- RF reflected power가 60 W를 3초 이상 초과하면 해당 랏을 홀드한다.
- 엔드포인트 신호 미검출 시 시간 모드 전환은 1회만 허용한다.

## 4. 후속 조치
식각 완료 후 챔버 시즈닝은 25랏마다 수행한다. 비상 배기 절차는 SF-9001 안전 스펙 5절을 따른다.
