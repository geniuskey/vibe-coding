# CV-3105 증착 공정 스펙 (가상 실습용)

> 본 문서는 워크숍 실습을 위한 **가상** 문서입니다. 실제 공정과 무관합니다.

## 1. 적용 범위
CVD-01/02 장비의 TEOS 산화막 증착 공정에 적용한다.

## 2. 공정 조건
| 항목 | 규격 | 비고 |
|---|---|---|
| 공정 온도 | 650 ± 10 °C | 히터 존 3점 평균 |
| 공정 압력 | 250 ± 20 mTorr | |
| TEOS 유량 | 120 ± 5 sccm | 버블러 온도 35 °C |
| 증착 속도 | 28 ± 3 nm/min | 주 1회 모니터 웨이퍼 검증 |

## 3. 품질 기준
- 두께 균일도(1σ/mean): 1.5% 이하
- 파티클(≥0.16 µm): 웨이퍼당 20개 이하 — 초과 시 챔버 클린 후 재검증
- 굴절률: 1.46 ± 0.01

## 4. 유지보수 연계
히터 교체 후에는 ES-2041과 동일하게 첫 3랏을 모니터 랏으로 운영한다.
진공 인터락 조건은 SF-9001 안전 스펙 3절을 따른다.
