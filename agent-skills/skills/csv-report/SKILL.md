# 일일 측정 리포트 생성

설비들이 뱉는 **표준 포맷 측정 CSV**를 병합·판정·시각화해서 HTML 리포트 한 장으로 만든다.

## 입력 포맷 (표준)

- 위치: 지정된 폴더의 `*.csv` (사용자가 폴더를 안 주면 물어볼 것)
- **맨 위 3줄은 설비 헤더** → 반드시 `skiprows=3`으로 건너뛴다
- 컬럼: `DATE, TOOL_ID, LOT_ID, WAFER_ID, STEP, THK_A, UNIF_PCT`
  - `THK_A`: 두께, 단위 Å (옹스트롬) — 단위 변환하지 말 것
  - `UNIF_PCT`: 균일도 %

## 절차

1. 대상 폴더의 CSV를 전부 읽는다 (`skiprows=3`, 인코딩은 `utf-8-sig` 우선, 실패 시 `cp949`).
2. 정규화: `LOT_ID`는 대문자 통일, `DATE`는 `YYYY-MM-DD` 통일.
3. 스펙 판정: `references/spec_table.md`의 STEP별 스펙으로 PASS/FAIL 컬럼 추가.
4. 집계: STEP×TOOL별 수율, FAIL 랏 목록, 두께 트렌드(일자별 평균±3σ).
5. 산출물: `report_YYMMDD.html` — **새 파일 생성이므로 라이브러리 자유**
   (pandas + matplotlib 권장, 차트는 트렌드 1개 + 수율 막대 1개).
6. 3일 연속 악화되는 TOOL이 있으면 리포트 상단에 ⚠️ 하이라이트로 표시한다.

## 검증 (필수 — 통과 못 하면 중단하고 보고)

- 병합 행수 = 파일별 행수의 합.
- `THK_A`에 음수/0이 있으면 해당 행을 리포트의 "데이터 이상" 섹션으로 분리.
- 스펙 표에 없는 STEP이 나오면 임의 판정하지 말고 사용자에게 물어본다.

## 하지 말 것
