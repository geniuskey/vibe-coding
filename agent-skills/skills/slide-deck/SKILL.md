# 발표 슬라이드 제작 (reveal.js 단일 HTML)

발표 슬라이드를 **빌드 없는 단일 `index.html`**(reveal.js)로 만든다.
디자인은 감으로 정하지 않는다 — 동봉된 `template.html`이 품질 기준 실물이다.

## 절차

1. **템플릿 복사로 시작한다.** 이 스킬 폴더의 `template.html`을
   `<발표폴더>/index.html`로 복사한 뒤 내용만 교체한다.
   디자인 토큰·컴포넌트·애니메이션·Reveal 설정이 이미 들어 있으므로
   스타일을 처음부터 짜지 말 것.
2. **목차부터 합의한다.** 주제·청중·발표 시간(분량)을 확인하고,
   슬라이드 목록(제목 한 줄씩)을 먼저 보여준 뒤 승인받고 진행한다.
   구성 문법: 타이틀 → 훅(공감/문제) → 본론(레벨·단계별) → 정리(3줄 요약) → Q&A.
3. **내용을 채운다.** 템플릿의 컴포넌트(`card`, `chip`, `pill`, `quote`,
   `flow`, `prompt-card`, `pre.code`, `grid-2/3`, `autoshow`)를 재사용한다.
4. **스스로 검증한다.** 완료 보고 전에 브라우저(가능하면 Playwright)로 열어
   전 슬라이드를 확인한다: 글자 넘침·요소 겹침·저대비·깨진 링크.
   문제는 보고 전에 스스로 고치고, 확인한 사실만 보고한다.

## 슬라이드 규칙 (판정 가능해야 한다)

- 한 슬라이드 본문 **6줄 이하**. 넘치면 장을 나눈다.
- 제목은 **한 줄**. 핵심 키워드에만 `.grad`(그라데이션) 강조.
- 슬라이드당 카드 최대 6장, 표 최대 6행 — 발표 화면(1280×800) 기준.
- 각 `<section>` 끝에 `<aside class="notes">` 발표자 노트를 1~3문장 넣는다.

## 디자인 토큰 (template.html과 동일 — 바꾸지 말 것)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--bg-0` | `#06080F` | 배경 |
| `--accent` | `#9B82FF` | 보라 — 주 강조 |
| `--accent-2` | `#2BEAD0` | 청록 — 긍정/코드 |
| `--accent-3` | `#FF7A95` | 분홍 — 경고/문제 |
| `--accent-4` | `#FFD46B` | 노랑 — 주의/보조 |

회사 CI 색을 요구받으면 `:root`의 토큰 값만 바꾸고 나머지 규칙은 유지한다.

## 하지 말 것

- 팔레트 밖의 새 색 도입 금지. 라이트 테마 금지.
- 외부 폰트 CDN 금지 — 시스템 폰트 스택(Pretendard 설치 시 사용)을 유지한다.
- 템플릿의 reveal.js는 편의상 CDN을 가리킨다. **발표 확정본은 reveal.js를
  로컬(`vendor/`)로 내려받아 CDN 링크를 교체**한다 — 오프라인 발표장 대비.
- 빌드 도구(npm 번들링 등) 도입 금지 — 단일 HTML을 유지한다.
- 검증 없이 "완성했습니다" 보고 금지.
