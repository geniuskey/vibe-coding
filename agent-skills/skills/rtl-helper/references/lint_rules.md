# 사내 Verilog 코딩룰 (연습용 발췌 — 팀 룰로 교체할 것)

| 룰 ID | 내용 | 근거 |
| --- | --- | --- |
| R01 | 조합 always는 `always @(*)`만 사용 (감지 리스트 수동 나열 금지) | 누락 시 시뮬-합성 불일치 |
| R02 | 조합 블록에서 모든 분기에 대입 (else 누락 금지) | latch 추론 방지 |
| R03 | 순차 블록은 non-blocking(`<=`), 조합 블록은 blocking(`=`) | 레이스 방지 |
| R04 | 대입 양변 비트 폭 일치 (암묵 확장/절단 금지) | 절단 버그 |
| R05 | 리셋은 비동기 assert / 동기 deassert, 이름은 `rst_n` | 팀 컨벤션 |
| R06 | 모듈당 clk 도메인 1개, 크로싱은 `sync_` 프리픽스 모듈로만 | CDC 관리 |
