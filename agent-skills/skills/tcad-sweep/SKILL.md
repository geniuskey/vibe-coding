# TCAD 파라미터 스윕 & 결과 수확

시뮬레이터(Sentaurus 등)는 그대로 두고, 그 **앞뒤** — 덱 생성과 결과 정리 — 를 자동화한다.
입력덱은 텍스트 파일이므로 취급 제약이 없다.

## 절차

### 1. 스윕 덱 생성
- 기준 덱(검증된 템플릿)에 `{tox}`, `{nd}` 같은 자리표시자를 둔 `template.cmd`를 사용.
- 스윕 조건은 **`sweep_plan.csv` 한 곳에서만** 관리 (컬럼 = 파라미터, 행 = 스플릿).
- 템플릿을 복사해 자리표시자만 치환한다. **물리 모델/메시 라인은 절대 수정하지 않는다**
  — 파라미터 값 외의 어떤 것도 바꾸지 않는 것이 이 스킬의 안전 경계다.
- 산출 덱/폴더 이름 = 조건 조합: `tox12_nd5e17/` (소수점은 `p`: `tox1p2`도 허용, 팀 표기 통일).

### 2. 실행 큐잉
- 클러스터 제출 명령·라이선스 규칙은 `references/cluster.md` 참조 (팀별 상이).
- 제출 전 스플릿 수 × 예상 시간을 보고하고 확인을 받는다 (라이선스 낭비 방지).

### 3. 결과 수확
- 각 스플릿의 출력에서 `Vg, Id` 시리즈를 추출해 **표준 CSV**로 저장:
  `컬럼 = VG_V, ID_A` / 파일명 = 조건 조합(`iv_tox12_nd5e17.csv`).
  이 포맷은 csv-report 스킬이 그대로 받아먹는다.
- 수렴 실패(convergence) 스플릿은 결과에 섞지 말고 별도 목록으로 보고.

### 4. 요약
- 스플릿별 Vth, SS(mV/dec), Ion/Ioff 표 생성.
- **Vth 추출법은 정전류법으로 통일**: `Id = 100 nA × W/L` 되는 Vg.
  (사람/스플릿마다 추출법이 다르면 비교가 불가능하다 — 다른 방법을 원하면 표에 방법을 명기.)
- 곡선 비교 그림: Id-Vg 로그 스케일, 스플릿별 색 구분, Vth 위치 점선 마커.

## 검증

- 생성한 덱 수 = sweep_plan.csv 행 수.
- 치환 후 덱에 자리표시자(`{`)가 남아 있으면 중단하고 보고.
- 추출한 I-V의 Id가 단조 증가 구간을 벗어나 요동치면 수렴 의심으로 플래그.

## 하지 말 것

- 물리 모델 파라미터를 "더 잘 맞게" 임의 조정하지 않는다 — 캘리브레이션은 담당자 영역.
- 수렴 실패를 조용히 빼고 평균 내지 않는다 (반드시 보고).
