PRE-FLIGHT CHECK

시작 전, 이 3가지부터 확인

🖥️ 내 노트북에 설치 권한이 있나? 회사 노트북은 관리자 권한이 잠긴 경우가 많습니다 — 사내 소프트웨어 센터나 사내 IT 헬프데스크로 설치 경로를 확인
🌐 사내망? 프록시? 개인망? 사내망은 프록시·인증서 때문에 다운로드가 막힐 수 있습니다. 오늘 실습이 개인 노트북이면 그냥 진행 OK
📜 회사의 AI 도구 정책은? 허용 도구 목록·데이터 반출 규정이 있다면 그것이 이 슬라이드보다 우선합니다
⚠️ 회사 노트북 + 사내망 조합은 변수가 가장 많습니다. 오늘 안 되면 붙잡고 있지 말고 에러 화면을 찍어 IT에 문의 — 그게 표준 절차입니다.
여기서 참가자 환경을 손들어 조사하면 좋다(개인 노트북 vs 회사 노트북). 회사 노트북 조는 프록시 이슈가 나올 확률이 높으니 조교를 미리 배치. "안 되는 게 정상일 수도 있다"고 미리 말해두면 심리적 좌절을 줄일 수 있다.
STEP 1 / 5 · 실습

터미널 열기 — 이미 갖고 있습니다

🪟 WINDOWS

Win 키 → "터미널" 또는 "PowerShell" 검색 → 실행

파란색/검은색 글자 창이 뜨면 성공. Windows 10 이하는 PowerShell을 쓰세요.

🍎 MAC

Cmd + Space → "터미널" 입력 → Enter

흰색/검은색 입력창이 뜨면 성공.

터미널은 글자로 대화하는 창일 뿐입니다. 명령어를 외울 필요는 없습니다 — 오늘 이후로는 AI가 대신 쳐 줍니다.
터미널 공포를 여기서 해소. "까만 화면 = 해커"라는 인상을 농담으로 풀기. 전원이 터미널을 띄운 것을 확인하고 다음으로. 이 단계에서 못 여는 사람은 거의 없다.

npm 방식으로 도구를 설치할 때의 밑바탕입니다. 다음 STEP의 공식 설치 스크립트를 쓰면 Node.js 없이도 되는 경우가 있지만, 실습·배포에서 두루 쓰이므로 깔아두면 두고두고 이득입니다.

"터미널을 껐다 켜야 반영된다"는 것을 크게 강조 — 설치 후 같은 창에서 재시도하다 실패하는 게 단골 패턴. 사내 소프트웨어 센터에 Node.js가 있으면 그쪽 경로가 더 빠를 수 있다.

🏢 사내망에서 다운로드가 막히면 억지로 우회하지 마세요 — 우리 회사의 공식 설치 경로(소프트웨어 센터·사내 안내 문서)가 우선입니다.

도구는 빠르게 바뀝니다 — 명령이 안 먹으면 공식 문서 code.claude.com/docs의 최신 설치 안내를 따르세요.

복사 버튼으로 그대로 붙여넣게 안내. Windows에서 PowerShell 실행 정책 에러가 나면 "관리자 PowerShell"로 다시 시도. 여기가 오늘의 첫 병목 — 조교가 순회하기 시작할 타이밍. 설치 스크립트/명령은 시점에 따라 바뀔 수 있으므로, 발표 전에 공식 문서와 대조해 한 번 검증할 것.

BILLING SENSE

비용의 감 — 토큰이라는 단위

🧮 토큰 = 글자 조각

AI는 주고받는 모든 글을 토큰으로 계산합니다. 대화가 길수록, 읽는 파일이 클수록 토큰이 늘어납니다.

⏳ 구독은 시간 단위 한도

구독 요금제는 보통 몇 시간 단위로 사용 한도가 차고 다시 풀립니다. 한도에 닿으면 쉬었다 하면 됩니다 — 고장이 아닙니다.

💡 아끼는 습관 하나

주제가 바뀌면 새 대화로 시작하세요. 긴 대화를 끌고 다니는 것이 토큰을 가장 많이 씁니다.

더 깊은 원리(컨텍스트 창)는 컨텍스트 세미나에서 다룹니다 — 오늘은 "긴 대화 = 비용"이라는 감만 가져가면 충분합니다.

입문자가 가장 자주 하는 질문 "얼마 들어요?"에 대한 답. 정확한 가격표 대신 과금의 구조(토큰, 시간 단위 한도)를 알려주는 것이 오래 간다. "한도가 찼습니다" 메시지를 처음 보면 고장으로 오해하고 문의가 온다 — 미리 예방주사.

워크숍의 "에러는 복붙" 규칙의 예고편. 설치 단계에서만 예외적으로 웹 챗봇을 쓰는 이유(도구가 아직 없으므로)를 설명하면 자연스럽다. IT 문의 시 "에러 원문 + 어느 단계였는지"를 함께 보내면 처리 속도가 몇 배 빨라진다.
SECURITY

시작 전 보안 3줄 약속

1️⃣ 회사 기밀·실데이터는 개인 계정 도구에 넣지 않습니다. 사내 승인 도구에서만 — 애매하면 넣지 않는 쪽이 정답.
2️⃣ API 키·비밀번호는 코드와 대화에 남기지 않습니다. 새 나갔다면 삭제가 아니라 재발급이 1순위.
3️⃣ 회사 정책이 항상 이 자료보다 우선합니다. 우리 회사의 허용 도구 목록·반출 규정을 먼저 확인하세요.

오늘 실습은 전부 공개해도 무방한 연습용 파일로만 진행합니다 — 그래서 마음 편히 실험할 수 있습니다.

워크숍의 보안 약속과 같은 내용의 축약판 — 첫 설치 시점부터 습관으로 심는 것이 목적. "애매하면 넣지 않는다"가 현장에서 가장 실용적인 판단 기준.
