게임 이름: 우주 퀴즈 탐험대
- 우주선 이름은 ‘별빛호’야.
- 아래 문제 은행 12개를 그대로 사용하고 질문·보기·정답·해설을 바꾸지 마.
- 한 게임에서는 그중 5문제를 겹치지 않게 골라서 보여줘.
- 문제마다 보기 3개를 큰 버튼으로 보여줘.
- 답을 고르면 정답인지 바로 알려주고 점수를 1점 올려줘.
- 현재 문제 번호와 점수를 화면 위에 보여줘.
- 시작 버튼과 다시 하기 버튼을 넣어줘.

문제 은행:
1. 우리가 사는 행성은? / 보기: 지구, 화성, 금성 / 정답: 지구 / 해설: 우리는 지구에서 살아요.
2. ‘붉은 행성’이라고 불리는 행성은? / 보기: 화성, 목성, 수성 / 정답: 화성 / 해설: 화성의 표면은 붉게 보여요.
3. 지구 주위를 도는 자연 위성은? / 보기: 달, 태양, 토성 / 정답: 달 / 해설: 달은 지구 주위를 돌아요.
4. 태양과 가장 가까운 행성은? / 보기: 수성, 금성, 지구 / 정답: 수성 / 해설: 수성은 태양에서 가장 가까운 행성이에요.
5. 태양은 무엇일까? / 보기: 별, 행성, 위성 / 정답: 별 / 해설: 태양은 스스로 빛을 내는 별이에요.
6. 크고 뚜렷한 고리로 유명한 행성은? / 보기: 토성, 지구, 화성 / 정답: 토성 / 해설: 토성은 눈에 잘 보이는 커다란 고리가 있어요.
7. 거미의 다리는 몇 개일까? / 보기: 8개, 6개, 4개 / 정답: 8개 / 해설: 거미는 다리가 8개예요.
8. 개구리의 아기를 무엇이라고 할까? / 보기: 올챙이, 애벌레, 송아지 / 정답: 올챙이 / 해설: 올챙이가 자라서 개구리가 돼요.
9. 하늘을 날 수 있는 포유류는? / 보기: 박쥐, 펭귄, 타조 / 정답: 박쥐 / 해설: 박쥐는 날개로 나는 포유류예요.
10. 지구에서 몸집이 가장 큰 동물은? / 보기: 대왕고래, 코끼리, 기린 / 정답: 대왕고래 / 해설: 대왕고래는 지구에서 가장 큰 동물이에요.
11. 문어의 팔은 몇 개일까? / 보기: 8개, 6개, 10개 / 정답: 8개 / 해설: 문어는 팔이 8개예요.
